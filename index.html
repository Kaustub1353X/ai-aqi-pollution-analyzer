About This Project

AI-AQI Pollution Analyzer is an AIML student project focused on understanding air-quality data and presenting it through an easy-to-use web interface.


Technology stack: HTML, CSS, JavaScript and, in future versions, Python, Machine Learning and real-world air-quality datasets.
